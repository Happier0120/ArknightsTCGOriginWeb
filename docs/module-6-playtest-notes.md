## 当前采用的规则解释

1. 同一事件产生多个触发时，当前回合玩家的能力优先；同一玩家控制的能力按部署位及实例 ID 确定顺序，不额外询问玩家排序。
2. 拦截者横置并成为最终攻击目标后，视为横置目标，因此浮士德能够获得本次攻击 ATK +2。
3. 塔露拉指令赋予的“额外失去1格生命”与基础战斗伤害在同一次战斗结果中合计处理；只产生一次击溃事件。
4. 场地的“每个你的回合限一次”按物理卡牌实例记录。另一张同名场地重新进入共享场地区后拥有独立次数。
5. 场地触发只检查事件发生时是否在场，不追溯场地进入前已经发生的撤退或击溃。
6. “本回合主动撤退过罗德岛干员”和“本回合有整合运动干员被击溃”均按离场卡牌的实际阵营校验。

## 建议重点观察

- 罗德岛的撤退链、救护站治疗和再部署节奏是否产生过强的资源循环。
- 整合运动连续击溃己方干员时，塔露拉、梅菲斯特、临时营地和亡语叠加后的操作时长是否过长。
- 两张场地均为2 DP，后手用新场地替换对手场地时，节奏收益是否足以覆盖卡差与费用。
- 玩家是否需要自行决定同一批触发的结算顺序；如果需要，当前自动排序界面应升级为排序步骤。
- 浮士德对拦截者获得 ATK 加成、塔露拉额外伤害的结算方式是否符合设计者预期。
- 七个等价部署位没有距离与邻接规则，是否足以支持后续卡牌设计。

## 模块 6.4 建议验收局面

1. 使用罗德岛救护站，撤退一名受伤的罗德岛干员，分别尝试发动和跳过治疗。
2. 同回合再次撤退受伤干员，确认同一场地不再触发。
3. 使用整合运动营地，击溃己方干员，确认不能选择刚被击溃的卡，但可以加速另一张候场卡。
4. 由对手使用新场地替换当前场地，确认旧场地进入原拥有者废弃区。
5. 部署碎骨并满足本回合击溃条件，确认只能选择敌方地面干员且 DEF 本回合降低2。
